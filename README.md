# SlackerRadio

Unofficial Hackclub's radio station over slacker news.

## Overview

SlackerRadio is an unofficial radio station project that operates over Slacker news. Broadcasts happen almost weekly or on an earlier schedule. Audio recordings are kept for a month before being deleted, with each broadcast linked to corresponding markdown  files.

## Features

- **Weekly Broadcasts**: Regular radio broadcasts over Slacker news
- **Audio Documentation**: Each broadcast is recorded and documented
- **Temporary Storage**: Broadcasts are retained for one month
- **Markdown Links**: Audio records are linked to MD files for easy reference
